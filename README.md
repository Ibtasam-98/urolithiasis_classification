# Project Overview
This repository contains the implementation and comparative analysis of deep learning architectures for classifying kidney stones in medical images. The study evaluates three neural network models — Deep Neural Network (DNN), Multi-Layer Perceptron (MLP), and Autoencoder-based DNN (AE-DNN) — on a dataset of 9,416 kidney images from Kaggle.
